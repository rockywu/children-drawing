## 验证范围

桌面安装包输出到 `release/`：Intel macOS、Apple Silicon macOS 的 DMG/ZIP，Windows x64 的 EXE。macOS 最低版本为 13.0。最终构建状态以本节下方的交付核对记录为准。

macOS 使用本地临时签名（ad hoc），没有 Apple Developer ID 签名或公证；Windows 没有 Authenticode 签名。未验证 Windows 真机安装、Apple Silicon 真机运行、DMG 拖拽安装、Safari、压感及儿童真人试用。

浏览器存储不是云备份。清理站点数据会删除作品；下载 PNG 可以保留独立图片。
Web 和桌面版数据各自保存，不自动互通。
