# 画画星球 · Web demo 骨架

目标：8～12 岁儿童可以独立开始画画、自由尝试、保存作品。中文、大字号、圆润卡通、柔和彩色；以作画为核心。

## 页面

1. 我的画室：首页。开始画画、灵感主题、最近作品。一个明确的主按钮。
2. 绘画画布：画笔、彩色笔、橡皮、形状、贴纸、调色、粗细、撤销/重做、清空、保存、导出 PNG、全屏。
3. 灵感乐园：少量主题，可选择喜欢的主题进入空白画布，参考图可关闭。
4. 作品小屋：本机作品缩略图、继续画画、删除确认。

## 技术边界

Vue 3 + TypeScript + Vite；原生 Canvas 与 Pointer Events 支持鼠标和触摸。页面状态保留在根组件，绘画实现放单独组件。浏览器 IndexedDB 保存图片与作品元数据，无后端和账号。保存失败必须明确告知，禁止把保存失败显示为成功。

在 Web demo 体验后，已按用户后续要求加入 Electron 主进程和打包配置，复用 Vue 界面。目标系统 macOS 与 Windows；各架构实际构建和运行状态以 verification.md 为准。

## 收敛范围

不做社区、排行榜、登录、课程体系、付费、AI 代画、复杂图层或聊天。避免竞争压力、弹出奖励和打断式提示。

## 检查范围

一次构建和类型检查；一次浏览器主流程检查：开始、绘画、撤销/重做、保存、重新打开、PNG 下载。验证桌面布局和窄屏基本可用。避免重复跑完整测试。

## 后续体验调整

- 自定义色板最多 8 个颜色，本地保存；右上角删除图标、删除二次确认。侧栏移除＋号和透明度/取色区域。默认色打开弹窗后，底部“✓ 用这个颜色”自动新增收藏并选中；自定义色打开弹窗后，底部为橙黄色带替换图标的“替换”和绿色“✓ 新增”。替换更新当前色块，新增保留原色；重复颜色合并，取消不改变收藏。区分选中的是默认色还是自定义色，即使两者 RGB 相同，也按实际点选的来源显示按钮；始终保留选择来源。
- 统一画画界面使用调色组件；支持圆形色盘、RGB、画布取色及 10%～100% 透明度（每档 10%）。圆盘控制色相和饱和度，明暗单独调整，无需拖动彩虹色相条。
- 满 8 个自定义色时，弹窗底部只保留橙黄色“替换”按钮；自定义色替换当前选中的色块，默认色替换第 8 个自定义色，成功后选中替换后的色块。未满时继续按默认色/自定义色展示原有按钮。
- 保留 Pointer Events 同时支持鼠标和触屏；圆形色盘也使用指针捕获。
- 画布查看缩放为 100%～200%，100% 为适应当前区域的完整画纸。画布下方滑条显示比例，旁边手掌按钮切换拖拽；再次点击或选择绘画工具恢复绘画。平板双指距离控制缩放、中点控制移动；第一指尚未完成的笔迹在进入双指手势时回滚，涂色桶/贴纸/取色延迟至单指抬起执行。双指手势结束后需全部抬指才恢复绘画。画布移动限制在可查看范围，缩放与平移不写入撤销历史或作品内容；窗口变化时重新限制边界。
- 粗细区为一行 4 个选项：4、10、20 和自定义图标，移除固定 32 档。下方自定义粗细滑条为 2～32、步长 2，拖动自动选择自定义档；固定档与自定义档的选中状态独立，自定义值在当前画室中保留。
- 缩放滑条每档 10%，双指缩放继续保持连续操作。缩放与粗细滑条明确使用绿色已选段/滑块及浅灰色未选段，避免系统主题产生黑色轨道。
- 画笔/彩色笔及涂色桶使用本地 SVG 工具指针，热点分别位于笔尖和油漆滴落处；拖拽模式优先显示手掌。橡皮使用独立于位图的圆形线框，直径与实际擦除共用同一计算（粗细×2.5），随画布视图同步缩放/移动。白色外线及深色内线保证在不同底色上可辨认；移出画布、切换工具、拖拽或双指手势时隐藏，触摸抬起时隐藏，不进入导出/保存/撤销记录。
- 工具栏删除独立取色入口，保留选色弹窗中的画布/屏幕取色。触屏设备上缩放、粗细和弹窗滑条的操作区至少 44px 高，画布滑条滑块为 24px；粗细按钮至少 44px 高。继续共用 Pointer Events，不按设备新增独立绘画流程。
- 填色修复采用抗锯齿边缘背景替换，保留实色轮廓，不使用高斯模糊。
- Electron 移除菜单而非仅自动隐藏；仅提供受限的原生全屏 IPC，关闭 Node 集成、开启隔离与沙箱。

- 界面简化：移除专注模式及切换入口，绘画始终使用同一界面，保留全屏按钮。
- 画纸提供 1:1、9:16、16:9、5:4、4:5、4:3、3:4、3:2、2:3，默认 4:3，长边 1000 像素。切换时完整等比居中放入新画纸，空余部分透明；比例变化进入撤销历史。作品保存宽高，旧版作品无尺寸字段时按原 1000×680 加载；缩放、绘画坐标、填色、橡皮、缩略图和 PNG 均使用当前尺寸。
- 调色、粗细、形状与贴纸选项统一放入默认收起的悬浮面板。展开不会改变画布区域；移出后延迟收起，点画布立即收起。图钉将面板固定到工具栏旁的左侧，固定后持续显示；选色弹窗保持独立显示，不因抽屉收起丢失状态。
- 移除右下角旧灵感卡片。主题 SVG 和自传图片由独立临摹小窗展示，图片完整等比显示；默认小图，标题栏拖动，右下角手柄调整整体宽高，点击查看大图。拖动和缩放均捕获 Pointer Events，限制在视窗内，触摸手柄至少 44px。上传校验大小与解码，失败保留旧参考图；临摹 Blob 随作品保存在同一 IndexedDB 记录，不写入绘画像素。
- 临摹小窗可切换“铺到画布临摹”，20% 不透明度的参考层置于透明绘画 Canvas 下方，同步画纸缩放和平移，禁用参考层的指针事件。小窗独立存在。保存原始透明笔迹及参考图/开关，缩略图与 PNG 导出补白，不合入临摹图。
- 临摹入口合并：顶部移除独立上传按钮；小窗显示时“临摹”按钮高亮，没有参考图时直接选择图片，有参考图（含内置主题）时切换显示。替换上传操作移到关闭按钮旁，使用醒目的橙黄色上传图标；取消或无效文件不改变旧图。底部只保留铺图按钮和右下角缩放图标手柄，等高对齐，触屏手柄为 44×44px。缩放继续支持拖动及方向键调整大小，悬浮面板收起入口位于临摹小窗下层，避免遮挡关闭按钮。
- 离开保护覆盖未保存的笔迹、名称、临摹上传和底图开关，以及保存中/未完成笔画。`beforeunload` 同时设置 `preventDefault` 与 `returnValue`；浏览器原生刷新/关闭弹窗受浏览器控制，不能添加保存按钮。页面收到刷新快捷键时提供保存并刷新/取消刷新，等待保存事务成功后才刷新；失败保留画布与弹窗。桌面端已有原生离开确认，本轮未重新打包。
