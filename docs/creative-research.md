## 四位专家的独立结论

| 专家 / 执行身份 | 原始优先级与分歧 | 对保护旧功能的意见 |
|---|---|---|
| 市场产品 `/root/creative_market` | 对称优先；另推魔法笔触、漫画、灵感。像素赞成，动画有条件采纳，必须可编辑保存全部帧并真实导出 GIF，不接受播放演示替代 | 独立工坊；不改旧画笔、调色、临摹、缩放和保存 |
| 艺术教育 `/root/creative_learning` | 对称、像素、动画能覆盖 8～12 的即时探索及 13～16 的徽章/角色/动作创作；灵感是辅助工具，不算第四个绘画模式；漫画下一轮 | 同意新增入口；反对重排主画板及改变既有输入语义 |
| 绘画引擎 `/root/creative_engine` | 对称、逻辑像素、12帧以内动画；保持可选结构化项目数据，未知版本不能空白覆盖；GIF 要独立解码验证 | 主画板手势、填色、透明层和历史风险高，应完全保留 |
| 视觉可用性 `/root/creative_visual` | 同意三种编辑器＋灵感；沿用奶油白/绿色/圆角/大字，64格为进阶；漫画与拼贴后置 | 允许新增一个侧导航、小块首页入口、作品类型角标/路由；反对更改旧核心操作 |

三位以上专家已明确同意入口与 gallery 类型路由调整，四位均反对改写 `PaintStudio.vue`。本期以新编辑器实现。随后引擎、视觉、像素交互三位专家明确批准一个例外：仅增加 `initialName?: string`，按 `artwork.name ?? initialName ?? 原默认名` 首次初始化名称，让灵感题目成为新画作名称；不加 watcher，不改绘制、调色、保存或旧 UI。

## 本期决定（T002）

1. **对称万花筒**：800×800 独立画纸，左右镜像、4/6/8 向；普通/彩虹/星星笔触，橡皮、辅助线、缩放/拖动、整笔撤销/重做、PNG、可编辑本地保存。每笔记住自身模式，后来切换模式不能改掉旧笔迹；半透明中心不能因镜像重复明显加深。
2. **像素创作**：16/32/64 方格，默认16；真实像素数组、画笔/橡皮/连通填色/取色、网格、缩放/移动、可编辑保存、整数放大 PNG。快速拖动补齐路径；改尺寸确认且可撤销，不能静默丢作品。
3. **翻页动画**：在相同像素语言上新增最多12帧、复制/新增/删帧/调整顺序、上一帧淡影、2～12fps 循环预览；保存全部帧及速度，下载真实 GIF 和 PNG 序列图。保留至少1帧；播放不编辑；辅助层不导出。GIF 最高256×256、固定量化色板、白底，由浏览器本地编码并独立解码验收。
4. **灵感抽签辅助**：本地“主体＋地点＋创作挑战”词库，可锁住喜欢的部分再抽；可带题目启动普通画室或三种新制作。无倒计时、评分、签到或网络生成。

年龄调整触达产品描述、网页元信息、PWA manifest、使用指南与新模式示例。保留原品牌和插画，不引入年龄账号或等级。

| 无缝图案/贴纸纸 | 后置，先验证跨边缘连续性才可命名无缝；对称已提供花纹入口 |

| AI 猜画/补画 | 不采纳，模型/服务依赖且偏离自主创作 |

## 共享契约与验收边界

- `src/creative/types.ts` 为编辑器接口：项目为 version=1 的可辨识联合类型。原 Artwork 新增可选 creative 字段，image/thumbnail 仍是 PNG 预览；无 creative 的旧作品继续普通画室，IndexedDB 不升级。
- 父 `CreativeStudio` 负责名称、ColorPalette、保存事务、下载、键盘保存/撤销和未保存离开/刷新保护；子编辑器只管理可编辑项目、绘制/历史，暴露 exportPng、undo/redo、cancelActive，动画附加 exportGif/exportSpriteSheet。
- 子组件 props：modelValue、color、opacity、disabled、pickMode；emit：update:modelValue（只在完成内容动作时）、history({canUndo,canRedo})、busy(boolean)、pick({color,opacity})、notice(string)。父保存中禁用所有修改；子笔画中发 busy 禁用保存，系统取消/双指加入回滚未结束笔迹。
- 图像导出无辅助线/网格/淡影。保存失败保持脏状态、画面与全部帧；未知项目不允许保存覆盖，仍可下载原 PNG。
- 两轮实际浏览器验收分别记录正常创作、失败/持久化/离线/触屏与旧画板回归；实体触屏没有使用时不声称真机通过。

## 第二轮构想审计（T010）

实现三种制作后，再由存储/前端工程、青少年创作产品/触屏和发布/艺术教育三个独立身份评议，保留可完整交付的范围。独立评议与生产检查见 [验证记录](creative-verification.md)。

- **采纳 `.artplanet` 完整备份和导入**：直接解决换电脑、清理浏览器和本地存储失败后的可编辑作品保全；保留全部笔迹、帧、速度和设置。仅使用浏览器 File API，导入新建作品，校验未知版本与损坏数据，不上传文件。两轮检查包含导出重开、全部帧/透明颜色保留及非法文件不覆盖原作。
- **漫画下一轮优先**：故事表达适合 8～16 岁，但需要中文输入、对白位置、独立分格及相应项目模型。几条分格线不能算完整漫画编辑器，本轮不塞入半成品。
- **无缝纹样后置**：与对称图案的价值重叠；需先验证跨边缘连续、平铺预览和导出一致。
- **声音联动后置**：声音解锁、静音、反馈节奏与触屏验证形成额外流程；麦克风还受非安全 HTTP 限制，对安静自主绘画收益有限。
- **AI 本轮不采纳**：网络/上传/密钥或大型本地模型增加依赖与性能负担，不符合本机自主创作边界。灵感词库已解决无从下笔的问题。

本轮探索后不再增加第四套制作界面，优先把三种玩法、保存与分享交付完整。没有把未实现候选写成已交付功能。
