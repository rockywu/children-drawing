# 画画星球

适合 8～12 岁的中文绘画软件，支持浏览器预览和 Electron 桌面版。Vue 3 + TypeScript + Vite，原生 Canvas 绘画。

## 预览

需要 Node.js 22.12+ 或 24。

```bash
npm install
npm run dev
```

打开终端打印的本机地址，默认 http://localhost:5173 。

同一局域网的其他电脑或平板可访问 `http://运行电脑的局域网IP:5173/`，支持绘画和本地保存。作品保存在访问设备的浏览器中。系统屏幕取色需要 HTTPS 或 localhost；局域网 HTTP 下仍可使用弹窗内的画布取色。

```bash
npm run build
npm run preview
```

## Web 部署与安装

运行 `npm ci && npm run build`，将 `dist/` 整个目录发布到画板服务器的 HTTP 静态服务。域名和 HTTPS 由 s2-lb 统一处理。支持站点根目录或以 `/` 结尾的子目录（例如 `/drawing/`）；不要只上传 `index.html`。

首页左下角有“保存为 Web App”入口。Chrome / Edge 支持时会打开系统安装确认，其他情况显示适合当前设备的操作步骤；Safari 可添加到程序坞，iPhone / iPad 可添加到主屏幕。Electron 和已用独立应用模式打开的页面隐藏此入口。系统安装需要用户确认，网页不能绕过系统权限。

局域网 HTTP 地址支持画画和本地保存，但浏览器会限制原生 Web App 安装与离线缓存，安装入口会显示手动操作说明。通过 s2-lb 的 HTTPS 域名访问可启用安全上下文中的安装与缓存能力；`localhost` 也是浏览器安全上下文例外。首次联网缓存后可离线打开、画画和保存。开发模式不启用离线缓存。缓存更新会等待所有画画窗口关闭后生效，不会自动刷新正在画的作品。

服务器应正确返回 JavaScript、PNG 与 `application/manifest+json` 类型。对 `index.html`、`sw.js` 和 `manifest.webmanifest` 使用 `Cache-Control: no-cache`；带哈希的 `assets/` 可使用长期缓存。子目录部署须保持完整目录结构，访问 `/drawing/` 而不是 `/drawing`，并避免将缺失的脚本或图片返回成 HTML。

Web App 的作品仍保存在当前设备、当前站点的浏览器存储中。切换域名、协议、端口或清理站点数据不会迁移作品；重要作品请下载 PNG。iOS 等系统添加到主屏幕后的存储可能独立，请先备份已有作品。

### 内网 Nginx 静态服务

服务器使用系统包管理器原生安装 Nginx，不使用 Docker 或反向代理。将完整 `dist/` 内容放到 `/opt/drawing/html/`，再安装项目的站点配置：

```bash
sudo install -m 644 deploy/drawing.nginx.conf /etc/nginx/sites-available/drawing
sudo ln -s /etc/nginx/sites-available/drawing /etc/nginx/sites-enabled/drawing
sudo nginx -t
sudo systemctl enable nginx
sudo systemctl reload nginx
```

画板服务器监听 `0.0.0.0:80`，Nginx 开机自启。内网入口为 `http://192.168.202.10/`，原 8001 端口已停用。Nginx 直接提供静态文件，不接收作品数据。

### s2-lb 域名入口与证书

域名入口：`https://drawing.wujialei.com:8000/`。主路由将公网 TCP 8000 映射到 `192.168.202.2:80`；s2-lb 的原生 Nginx 使用 `deploy/drawing-lb.nginx.conf`，在 80 端口处理 TLS，再转发到 `http://192.168.202.10/`。部署时需禁用 s2-lb 的 Nginx 默认欢迎站点，原 8080 TLS 监听保留。HTTP 返回 308 跳转到 HTTPS，保留访问端口、路径和查询参数。2026-10-18 独立公网节点确认 18080 TCP 连通，配置调整后用户确认 18080 可以访问，随后将公网入口改为 8000；本机验证 8000 的 TLS、画板构建内容和跳转正确。原公网 8080 入站超时的具体原因未确定。

证书同步工具为 `deploy/fnos-ssls-sync.py`，部署于 s2-lb 的 `/usr/local/sbin/fnos-ssls-sync`。它通过验证 TLS 的 `https://nginx.wujialei.com:18443` 拉取授权的 `*.wujialei.com`，连接地址固定为 `192.168.202.202`。凭据来自服务器本机 `/home/rocky/nginx.wujialei.com.md`，只保存在 root 可读的 `/etc/fnos-ssls-sync/auth.header`，不得提交到 Git；连接配置为同目录的 `config.json`。

证书位于 `/etc/nginx/ssl/wildcard.wujialei.com/versions/`，`current` 符号链接成套选择证书和私钥。root crontab 每分钟执行一次同步，开机也执行一次；日志为 `/var/log/fnos-ssls-sync.log`，每周轮转。版本未变且实际监听证书一致时不下载或重载；证书变化时校验信任链、有效期、域名、指纹和密钥匹配，再切换链接、检查配置和重载，并核对实际 TLS 证书。失败保留或恢复旧版；429 退避 5 分钟。互斥锁避免手动与定时任务重叠。

证书变更检查使用 `python3 deploy/test_fnos_ssls_sync.py`。服务器手动检查可执行 `sudo /usr/local/sbin/fnos-ssls-sync`；无变化时不输出日志。

## 可以体验

- 我的画室：开始创作、4 个原创插画主题、最近作品。
- 画纸比例可选 1:1、9:16、16:9、5:4、4:5、4:3、3:4、3:2、2:3，新作品默认 4:3。切换时等比居中保留整幅画，可撤销；保存和 PNG 导出使用实际比例，旧作品保留原尺寸。
- 调色与粗细默认以悬浮抽屉展示，不挤占画布；点击“调色 / 粗细”展开，离开面板后自动收起，点画布直接收起。图钉可固定到左侧，再次点击恢复悬浮。形状和贴纸工具会展开相应选项。
- 临摹图默认以悬浮小窗展示：拖动标题栏移动位置，拖动右下角手柄调整整体大小，点击图片放大查看。支持鼠标和触屏，图片保持原比例。可上传 20MB 以内、2500 万像素以内的浏览器支持图片；临摹图片随作品保存在本浏览器，不写入画作或导出的 PNG。
- 临摹小窗的“铺到画布临摹”将图片以 20% 不透明度放在笔迹底层，方便描画；小窗继续保留，可随时移除底图。参考图片和底图开关随作品保存，PNG 仅导出自己的画作。作品内部保留透明笔迹，导出仍为白底。
- 顶部仅保留“临摹”入口，小窗打开时高亮；已有参考图时点击显示/隐藏，没有参考图时打开图片选择。内置主题参考图也可直接开关。替换上传图片使用关闭按钮旁的橙黄色图标；底部保留铺图按钮和右下角拖动缩放手柄，两者等高对齐。替换图片后同步更新临摹底图。
- 未保存时拦截刷新与关闭：页面收到 F5、Ctrl/Cmd+R 时显示“保存并刷新 / 取消刷新”；保存失败留在页面。浏览器工具栏刷新、关闭标签或窗口使用浏览器原生离开确认框，只能选择离开或取消；需要保存时先取消，再点击“保存作品”。已保存且没有新修改时不打断操作。
- 绘画：画笔、半透明彩色笔、橡皮、涂色桶、贴纸；9 种形状：椭圆、矩形、直线、三角形、五角星、爱心、菱形、五边形、六边形。
- 调色盘、自选色；粗细一行 4 个选项：4、10、20 三个固定档位及自定义档。下方滑条支持 2～32、每档 2，调整后自动选中自定义档，再次点击自定义档可恢复上次设置。最近 15 步撤销/重做、清空后撤销。
- 基础颜色下方可收藏最多 8 个自定义颜色。选中默认色后打开选色弹窗，点击“用这个颜色”自动收藏并选中；选中自定义色时，弹窗提供橙黄色“替换”和绿色“新增”，分别更新当前色块或保留原色并新增。色块右上角删除图标需要二次确认；本浏览器持久保存，统一画画界面使用同一套调色盘。重复颜色会合并。
- 满 8 个颜色时，选色弹窗底部只显示“替换”：选中自定义色时替换当前色块；选中默认色时替换第 8 个自定义色，并选中替换后的颜色。
- 圆形色盘直接选色、明暗调整、RGB 输入、透明度、画布取色均集中在选色弹窗内；支持的浏览器还提供屏幕取色。
- 透明度默认 100%，10%～100%，每档 10%；画笔、形状、填色、贴纸均使用当前透明度。
- 统一画画界面，保留全屏按钮；未保存离开确认；作品名称可修改。
- 首页和画布都有全屏按钮；桌面版移除 File/Edit/View/Window 菜单，Alt 不会唤回菜单。
- 本地保存、作品小屋、继续绘画、删除确认、白底 PNG 下载。
- 支持鼠标、触摸和画笔指针，中文系统字体，无远程图片和字体依赖。
- 工具指针随选择切换：画笔/彩色笔为笔刷、涂色桶为油漆桶、拖拽模式为手掌；橡皮显示实际擦除直径的圆形线框，随粗细和画布缩放变化，触摸按下时可见。线框只作预览，不写入作品。
- 左侧移除独立取色按钮；画布取色保留在选色弹窗。触屏下放大滑条操作区及滑块，粗细选项至少 44px 高；橡皮抬指隐藏预览，涂色桶单指抬起时执行，双指手势不误擦或误填。
- 画布下方支持 100%～300% 查看缩放（滑条每档 10%）及手掌拖拽开关。平板可双指缩放和移动，单指继续绘画；切入双指手势会撤回当前未结束的笔迹，避免误画。缩放不改变作品像素尺寸，100% 表示完整画纸适应当前画布区域。缩放与自定义粗细滑条使用绿色已选段、浅灰色背景。

快捷键：`⌘/Ctrl + Z` 撤销，`⌘/Ctrl + Shift + Z` 重做，`⌘/Ctrl + S` 保存。

作品保存在当前浏览器的 IndexedDB。换浏览器或清理网站数据后不会保留，重要作品请下载 PNG 备份。不会上传作品。

## 桌面版

```bash
npm run desktop    # 构建 Web 并启动 Electron
npm run dist:mac   # 在 macOS 构建 Intel / Apple Silicon 的 DMG 和 ZIP
npm run dist:win   # 构建 Windows x64 安装程序
```

安装文件位于 `release/`。macOS 包最低系统版本为 macOS 13；Windows 使用 x64 安装程序。macOS 使用本机临时签名，未做 Apple 开发者签名及公证；Windows 未做 Authenticode 签名。首次启动可能出现系统来源确认。

Web 和桌面版各自保存作品与自定义调色板，不会自动互通。桌面版可离线绘画。构建和运行验证范围见 [docs/verification.md](docs/verification.md)。

设计、调研和专家意见见 [docs/design.md](docs/design.md)。
